# MNIST Digit Recognizer

## Overview

This project uses Deep Learning to recognize handwritten digits from images.

## Features

* TensorFlow/Keras Neural Network
* MNIST Dataset
* Image Upload Support
* Streamlit Web Interface
* Confidence Score Display

## Tech Stack

* Python
* TensorFlow
* NumPy
* Pillow
* Streamlit

## Dataset

MNIST Handwritten Digits Dataset

## Model Performance

Accuracy: 98.66%

## Workflow

Digit Image → Image Preprocessing → Neural Network → Digit Prediction

## Example

Input: Handwritten digit image

Output: Predicted Digit = 7
